# Project_Rock-Paper-Sissor

This is my first Project for my Intro ti Linux class 

- Description -

This is a Rock, Paper, Scissors game written in Bash. The player competes against the computer, and the game keeps track of wins, losses, and ties.

- What I had added -

Player can choose Rock, Paper, or Scissors.

Computer randomly selects a choice.

Determines the winner using classic game rules.

Keeps track of player and computer scores.

Allows multiple rounds.

Displays the final score when the player quits.

- Requirements - 

Linux operating system

Bash shell

- How to Run -

Open a terminal.

Navigate to the directory containing the script.

Make the script executable:

chmod +x bash-RPSGame.sh

Run the game:

./bash-RPSGame.sh 

- How to Play - 

Enter 1 or Rock to choose Rock.

Enter 2 or Paper to choose Paper.

Enter 3 or Scissors to choose Scissors.

Enter Q to quit the game
